# Luphonix React Website

## Overview
This is a sophisticated React-based website for Luphonix Digital Innovation Agency. The application showcases advanced 3D graphics, animations, and interactive elements using modern web technologies including Three.js, WebGL, and Spline 3D scenes.

## Project Architecture
- **Frontend**: React 18 with React Router for navigation
- **Styling**: Custom CSS with utility classes and CSS variables for theming
- **3D Graphics**: Three.js, React Three Fiber, Spline 3D models
- **Animations**: Framer Motion, GSAP for advanced animations
- **Build System**: Create React App (react-scripts)
- **Package Manager**: npm

## Key Features
- Interactive 3D models and WebGL scenes
- Advanced animations and particle effects
- Responsive design with multiple themes
- Blog functionality with admin interface
- Contact forms and service showcases
- SEO-optimized with structured data
